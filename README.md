# music_website_vue3
## 项目简介
- 这是一个音乐网站，基于Vue3，使用Element-plus进行前端UI，使用axios进行数据请求，使用pinia进行全局数据管理，使用vue-router进行路由管理，使用vue-cli进行项目构建，使用vue-cli进行项目构建; 后端使用Express框架，使用mysql数据库，用nginx进行服务器代理，使用腾讯云COS云存储进行文件存储
## 项目技术栈
- Vue3 + Vue/Cli + Pinia + Vue-router + Axios + Express + Mysql + Nginx + Tencent Cloud COS

## 网站功能
- 登录注册
- 音乐播放
- 音乐收藏
- 音乐搜索
- 音乐推荐
- 歌单管理
